# Лабораторная 3.8 — дерево оптимального поиска (точный алгоритм)

Построение ДОП по матрицам `AW`, `AP`, `AR` из лекции.

- [manual.md](manual.md) — ручное построение для ФИО «ЯЗИКОВ ДЕНИС АЛЕКСАНДРОВИЧ», первые четыре неповторяющихся символа.
- `main.c` — генерация упорядоченных ключей, матрицы, построение дерева, обход и таблица для N = 100, 200, 300, 400, 500.
- `svg.c` — изображение дерева с ключами и весами вершин.
- `preview.html` — просмотр SVG в браузере.

Запуск из каталога `saod2`:

```sh
make run-dop
```

По умолчанию программа показывает три матрицы для 10 вершин. Для 100 вершин:

```sh
./build/dop 100
```

Выводятся обход 100 вершин слева направо, проверка `AP[0,n] / AW[0,n]` и таблица характеристик. SVG-файлы `dop10.svg` и `dop.svg` создаются в каталоге `saod2`, а `labs/dop/preview.html` показывает их в браузере.
