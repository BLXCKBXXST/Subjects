# 3.2 — идеально сбалансированное дерево поиска (ИСДП)

Основной файл — `main.c`: генерация 100 разных чисел, сортировка, построение ИСДП, обход и четыре характеристики. Основной алгоритм легко показать отдельно; всё вспомогательное разнесено по файлам.

- `compare.c` — дополнительные таблицы для деревьев из 100, 200, 300, 400 и 500 вершин.
- `treeprint.c` — изображение дерева в терминале.
- `search.c` — рекурсивный поиск.
- `search_iterative.c` — итеративный поиск (заменяет `search.c` при сборке без изменений `main.c`).

Из корня репозитория:

```sh
make -C saod2 build/isdp build/isdp-iterative
./saod2/build/isdp
./saod2/build/isdp-iterative
```

При запуске обеих версий числа генерируются случайно заново, поэтому результаты разных запусков могут отличаться. Для следующего задания см. [3.3 — СДП](../sdp/).
