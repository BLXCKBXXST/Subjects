# Лабораторные САОД 2

- [**3.2 — ИСДП**](isdp/): основная программа `main.c`, два варианта поиска (`search.c` / `search_iterative.c`), отдельные таблица и визуализация.
- [**3.3 — СДП**](sdp/): короткий `main.c`, две реализации вставки (`recursive.c` / `double.c`), дополнительная сравнительная таблица и визуализация.

- [records](records/) — обработка записей.
- [substring-search](substring-search/) — поиск подстроки.

Сборка для обеих лабораторных настроена в [общем Makefile](../Makefile); запуск — из корня репозитория, команды приведены в [README САОД 2](../README.md).
