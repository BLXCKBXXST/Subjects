# АВЛ-дерево

Задание 3.5 запускается командой `make run-avl` из каталога `saod2`.

Для задания 3.6 запустите `make run-avl-delete`. Программа строит дерево из 100 разных случайных ключей, выводит их по возрастанию и просит удалить 10 ключей. Если ключ не найден, попытка не входит в число десяти удалений.

Число вершин исходного дерева задаётся переменной `vertexCount` в начале `main` файла `main_delete.c`. Можно задать от 1 до 1000 вершин. После изменения просто запустите `make run-avl-delete` снова. Удаляется не более 10 вершин.

После построения дерево откроется в браузере через `labs/avl/delete_preview.html`. После каждого успешного удаления рисунок в этой же вкладке обновляется автоматически. Кнопки «Назад» и «Вперёд» позволяют просмотреть сохранённые шаги. Если браузер не открылся автоматически, откройте этот файл вручную из каталога `saod2`. Рисунки `avl-delete-0.svg`, `avl-delete-1.svg` и далее сохраняются там же.

`deleteAVL` возвращает 1, если ключ удалён, и 0, если его нет. При удалении вершины с двумя потомками её ключ заменяется максимальным ключом левого поддерева. Переменная `Umen` сообщает рекурсивным вызовам, уменьшилась ли высота поддерева. `RR1` и `LL1` нужны, когда после удаления соседний потомок имеет баланс 0: поворот восстанавливает баланс, но высота нового поддерева не уменьшается.
