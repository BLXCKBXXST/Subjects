# АВЛ-дерево

Задание 3.5 запускается командой `make run-avl` из каталога `saod2`.

Для задания 3.6 запустите `make run-avl-delete`. Программа строит дерево из 100 разных случайных ключей, выводит их по возрастанию и просит удалить 10 ключей. После каждого успешного удаления печатается новый обход дерева и сохраняется рисунок. Если ключ не найден, попытка не входит в число десяти удалений.

Для проверки ручного задания запустите `make run-avl-delete-manual`. Введите 12 разных числовых кодов символов в порядке построения дерева. Программа удалит их в том же порядке и покажет обход после каждого удаления, в том числе пустое дерево в конце.

Число вершин задаётся переменной `vertexCount` в начале `main` файла `main_delete.c`: первое число после `manual ?` относится к ручному режиму, второе — к случайному. После изменения пересоберите программу командой `make build/avl-delete`. Можно задать от 1 до 1000 вершин. В случайном режиме удаляется не более 10, в ручном — все введённые вершины.

По завершении откроется `labs/avl/delete_preview.html`. Кнопки «Назад» и «Вперёд» показывают исходное дерево и рисунок после каждого успешного удаления. Если браузер не открылся автоматически, откройте этот файл вручную из каталога `saod2`. Рисунки `avl-delete-0.svg`, `avl-delete-1.svg` и далее сохраняются там же.

`deleteAVL` возвращает 1, если ключ удалён, и 0, если его нет. При удалении вершины с двумя потомками её ключ заменяется максимальным ключом левого поддерева. Переменная `Umen` сообщает рекурсивным вызовам, уменьшилась ли высота поддерева. `RR1` и `LL1` нужны, когда после удаления соседний потомок имеет баланс 0: поворот восстанавливает баланс, но высота нового поддерева не уменьшается.
