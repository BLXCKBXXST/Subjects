# АВЛ-дерево

Задание 3.5 запускается командой `make run-avl` из каталога `saod2`.

Для задания 3.6 запустите `make run-avl-delete`. Программа строит дерево из 100 разных случайных ключей, выводит их по возрастанию и просит удалить 10 ключей. После каждого успешного удаления печатается новый обход дерева. Если ключ не найден, попытка не входит в число десяти удалений.

Для проверки ручного задания запустите `make run-avl-delete-manual`. Введите 12 разных числовых кодов символов в порядке построения дерева. Программа удалит их в том же порядке и покажет обход после каждого удаления.

`deleteAVL` возвращает 1, если ключ удалён, и 0, если его нет. При удалении вершины с двумя потомками её ключ заменяется максимальным ключом левого поддерева. Переменная `Umen` сообщает рекурсивным вызовам, уменьшилась ли высота поддерева. `RR1` и `LL1` нужны, когда после удаления соседний потомок имеет баланс 0: поворот восстанавливает баланс, но высота нового поддерева не уменьшается.
