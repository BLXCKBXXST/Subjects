# 3.3 — СДП

В `main.c` — построение дерева на 100 вершинах, обход и характеристики. Два способа вставки — в `recursive.c` и `double.c`, таблица — в `compare.c`, рисунки деревьев — в `treeprint.c`.

```sh
make -C saod2 run-sdp-recursive
make -C saod2 run-sdp-double
```

При обычном запуске сразу выводятся таблица и все три дерева сверху вниз.
