# 3.3 — СДП

Одна программа строит ИСДП и два СДП из одинаковых 100 чисел. В `main.c` — оба способа вставки, таблица вынесена в `compare.c`, SVG-рисунки — в `treeprint.c`.

```sh
make run-sdp
```

После запуска создаются `sdp-isdp.svg`, `sdp-sdp.svg` (СДП1) и `sdp-sdp2.svg` (СДП2). В SVG есть малозаметные разделители уровней; ссылки на файлы появляются в терминале.

Если установлен `chafa`, `make run-sdp` дополнительно показывает **настоящие миниатюры SVG прямо в терминале** (ИСДП и СДП; СДП2 визуально совпадает с СДП1). Без `chafa` программа продолжает работать и создавать SVG.

Для встроенного терминала VS Code включить в настройках JSON:

```json
"terminal.integrated.enableImages": true
```

VS Code поддерживает картинки через iTerm/Sixel; `chafa --format iterm` использует нужный протокол. Нужна версия `chafa` с поддержкой SVG (`chafa --version`).
