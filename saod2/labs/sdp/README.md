# 3.3 — СДП

Одна программа последовательно строит деревья для 100, 200, 300, 400 и 500 различных чисел. В каждом выводе — общий симметричный обход, сравнительная таблица ИСДП/СДП1/СДП2, ссылки на три SVG и символьные превью через `chafa`.

```sh
make run-sdp
```

Для 100 вершин файлы называются `sdp-isdp.svg`, `sdp-sdp.svg`, `sdp-sdp2.svg`. Для остальных выводов к имени добавляется размер: например, `sdp-isdp-200.svg`. Между уровнями SVG проведены полупрозрачные горизонтальные линии.

Если `chafa` не установлен, таблицы, ссылки и SVG всё равно создаются. Установка в Linux Mint: `sudo apt install chafa`.
