# 3.3 — СДП

Программа строит ИСДП, СДП1 и СДП2 из одной последовательности случайных чисел. В терминале один обход для n=100, сводная таблица для N=100, 200, 300, 400 и 500, затем ссылки и символьные превью трёх деревьев с 100 вершинами.

```sh
make run-sdp
```

Рисунки автоматически сохраняются в общей папке `images`, в подпапке лабораторной `images/sdp`: `sdp-isdp.svg`, `sdp-sdp.svg` и `sdp-sdp2.svg`. Ссылки и символьные превью работают с новыми путями. Между уровнями SVG проведены полупрозрачные линии. Для символьного превью нужен `chafa` (`sudo apt install chafa`).
