# 3.3 — СДП

Программа строит ИСДП, СДП1 и СДП2 из одной последовательности случайных чисел. В терминале выводятся обход, сводная таблица для N = 100, 200, 300, 400 и 500, ссылки и символьные превью трёх деревьев с 100 вершинами.

Поиск устроен так же, как в 3.2: нужный вариант подключается при компиляции.

Рекурсивный поиск:

```sh
make run-sdp
```

Нерекурсивный поиск:

```sh
make run-sdp-iterative
```

В обоих случаях после вывода деревьев программа спрашивает количество ключей и ждёт ввода. Если ввести 0, программа завершается.

Структура основной части:
- `main.c` — два способа построения СДП и основной ход программы;
- `search.c` — рекурсивный поиск;
- `search_iterative.c` — нерекурсивный поиск;
- `common.c` — общие функции дерева;
- `compare.c` — сравнение деревьев и временные SVG;
- `treeprint.c` — построение SVG.

SVG `sdp-isdp.svg`, `sdp-sdp.svg` и `sdp-sdp2.svg` существуют только пока работает программа. При обычном завершении и при `Ctrl+C` они удаляются.


## Вариант с повторяющимися ключами

Для отдельной проверки разрешены повторяющиеся числа. Равный ключ добавляется в правое поддерево. Первые два элемента массива специально делаются одинаковыми, поэтому хотя бы один повтор гарантирован.

Рекурсивный поиск:

```sh
make run-sdp-repeat
```

Нерекурсивный поиск:

```sh
make run-sdp-repeat-iterative
```

Обычные `run-sdp` и `run-sdp-iterative` не изменены.

## 3.4 — удаление из СДП

```sh
make run-sdp-delete
```

Программа спрашивает размер дерева (от 1 до 1000) и сколько вершин удалить
(от 1 до размера дерева). Она строит СДП из разных случайных чисел и выводит
их по возрастанию. Введите по очереди ключи из этого списка. Изображение дерева
открывается в браузере и обновляется после каждого удаления; сам рисунок
сохраняется в `sdp-delete.svg`. В терминале после каждого удаления печатается
обход слева направо. Если ключа нет, программа просит другой ключ; такое
удаление не входит в счёт. Вершина с двумя потомками заменяется наибольшей
вершиной из её левого поддерева.

Показ изображения работает в графическом сеансе Linux через `xdg-open`.
Если браузер не открылся автоматически, откройте `labs/sdp/delete_preview.html`.
