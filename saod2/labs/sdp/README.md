# 3.3 — СДП

Одна программа строит ИСДП и два СДП из одинаковых 100 чисел. В `main.c` — оба способа вставки, таблица вынесена в `compare.c`, рисунки — в `treeprint.c`.

```sh
make run-sdp
```

После запуска создаются `sdp-isdp.svg`, `sdp-sdp.svg` (СДП1) и `sdp-sdp2.svg` (СДП2). Ссылки на них появляются в терминале. СДП1 и СДП2 имеют одинаковую форму, поскольку строятся из одной последовательности.
