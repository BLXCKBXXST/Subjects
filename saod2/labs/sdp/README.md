# 3.3. Случайное дерево поиска

Основная программа — `main.c` (27 строк): одна последовательность из 100 различных чисел, вставка в СДП, обход и четыре характеристики. Дополнительная функциональность не загромождает `main.c`: один вызов `printStats` и один необязательный вызов `printExtras`.

- `recursive.c` — рекурсивная вставка (СДП1).
- `double.c` — вставка с двойной косвенностью `struct Node **` (СДП2).
- `common.c` — генерация, обход, характеристики и очистка памяти.
- `compare.c` — ИСДП, СДП1 и СДП2 из одной последовательности; таблица и обходы.
- `treeprint.c` — консольная визуализация, дополнительный пункт 5*.
- `ручное-построение.md` — пункт 1, пример с 12 символами ФИО.

## Сборка и запуск

Из корня репозитория:

```sh
make -C saod2 build/sdp-recursive build/sdp-double
./saod2/build/sdp-recursive
./saod2/build/sdp-double
./saod2/build/sdp-recursive +
./saod2/build/sdp-double +
```

Обычный запуск показывает только обход и четыре характеристики. Параметр `+` добавляет таблицу ИСДП/СДП1/СДП2, оба обхода и горизонтальное изображение. Альтернативный вариант выбирается флагом компиляции `-DUSE_DOUBLE`; менять `main.c` не нужно.

Прямая сборка из `labs/sdp`:

```sh
gcc -std=c11 -Wall -Wextra main.c recursive.c double.c common.c compare.c treeprint.c -o sdp-recursive
gcc -std=c11 -Wall -Wextra -DUSE_DOUBLE main.c recursive.c double.c common.c compare.c treeprint.c -o sdp-double
```

Из одинаковой последовательности обычные СДП обоими способами вставки получаются идентичными по форме и характеристикам. Сравниваются алгоритмы вставки, а не независимые случайные деревья.
