# 3.3 — СДП

Одна программа строит ИСДП и два СДП из одинаковых 100 чисел. В `main.c` — оба способа вставки, таблица вынесена в `compare.c`, SVG-рисунки — в `treeprint.c`.

```sh
make run-sdp
```

После запуска создаются `sdp-isdp.svg`, `sdp-sdp.svg` (СДП1) и `sdp-sdp2.svg` (СДП2). SVG содержат малозаметные разделители уровней.

В терминале для каждого дерева подряд выводятся ссылка, символьное превью через `chafa`, пустая строка — затем ссылка на следующее дерево. Если `chafa` не установлен, ссылки и SVG всё равно работают. Для установки в Linux Mint: `sudo apt install chafa`.
