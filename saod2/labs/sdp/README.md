# 3.3 — СДП

В `main.c` — дерево на 100 вершинах, обход и характеристики. Два способа вставки — в `recursive.c` и `double.c`. Таблица и компактный рисунок деревьев выводятся сразу.

```sh
make run-sdp-recursive
make run-sdp-double
```

Полные рисунки трёх деревьев также сохраняются в `sdp-trees.txt` в папке, откуда запущена программа.
