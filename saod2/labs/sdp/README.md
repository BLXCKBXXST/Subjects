# 3.3 — СДП

В `main.c` — дерево на 100 вершинах, обход и характеристики. Два способа вставки вынесены в `recursive.c` и `double.c`. Таблица и изображение дерева — отдельно.

```sh
make -C saod2 run-sdp-recursive
make -C saod2 run-sdp-double
```

Для таблицы и рисунка запусти `./saod2/build/sdp-recursive +`. Ручное задание — в [отдельном файле](ручное-построение.md).
