# 3.3 — СДП

Программа строит ИСДП, СДП1 и СДП2 из одной последовательности случайных чисел. В терминале выводятся обход, сводная таблица для N = 100, 200, 300, 400 и 500, ссылки и символьные превью трёх деревьев с 100 вершинами.

После этого программа показывает меню поиска: `1` — рекурсивный, `2` — нерекурсивный, `0` — выход. После выбора вводится количество ключей. После выполнения поиска программа возвращается в меню, поэтому можно переключаться между двумя вариантами без перезапуска.

```sh
make run-sdp
```

Структура основной части:
- `main.c` — два способа построения СДП и основной ход программы;
- `search.c` — рекурсивный поиск и ввод ключей;
- `search_iterative.c` — нерекурсивный поиск;
- `common.c` — общие функции дерева;
- `compare.c` — сравнение деревьев и временные SVG;
- `treeprint.c` — построение SVG.

SVG `sdp-isdp.svg`, `sdp-sdp.svg` и `sdp-sdp2.svg` существуют только пока работает программа. При обычном завершении и при `Ctrl+C` они удаляются. Отдельная папка для них не создаётся.
