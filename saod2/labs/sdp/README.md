# 3.3 — СДП

Программа строит ИСДП, СДП1 и СДП2 из одной последовательности случайных чисел. В терминале выводятся обход, сводная таблица для N = 100, 200, 300, 400 и 500, ссылки и символьные превью трёх деревьев с 100 вершинами.

После этого программа ждёт ввод количества ключей. Для каждого введённого ключа выполняются оба варианта поиска: рекурсивный и нерекурсивный. Если ввести 0, программа завершается.

```sh
make run-sdp
```

SVG создаются временно прямо в каталоге `saod2`: `sdp-isdp.svg`, `sdp-sdp.svg`, `sdp-sdp2.svg`. Пока программа ждёт ввод ключей, файлы можно открыть по ссылкам из терминала. При обычном завершении и при `Ctrl+C` SVG удаляются. Папка `images` больше не создаётся.

Оба способа вставки (`insertRecursive` и `insertDouble`) и оба способа поиска находятся в `main.c`, чтобы их было удобно показывать на защите.
