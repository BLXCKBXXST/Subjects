# Лабораторная 3.7 — двоичное Б-дерево поиска

Реализована по лекции `5_DBD.pptx`, слайды 7–8 (`B2INSERT`), и по методичке `Задания по алгоритмам обработки деревьев.pdf`, раздел 3.7.

1. **Ручное построение** из первых 12 неповторяющихся букв ФИО приведено в [manual.md](manual.md).
2. **Добавление ключа**: функция `B2INSERT` в `dbd.c` соответствует псевдокоду лекции. `VR` и `HR` устанавливаются перед каждой вставкой в `main.c`, отдельной обёртки для вставки нет.
3. **100 случайных вершин**: `main.c` строит ДБД и печатает обход слева направо.
4. **Сравнение с АВЛ**: по одной последовательности из 500 неповторяющихся ключей строятся АВЛ и ДБД, выводится таблица размера, контрольной суммы, высоты и средней высоты для N = 100, 200, 300, 400 и 500.
5. **Дополнительно**: функция `pageLevels` вычисляет количество уровней *логических страниц* ДБД.
6. **Дополнительно**: SVG `dbd.svg` изображает страницы и их связи. SVG использует более узкую и высокую компоновку; изображаются первые 100 ключей, чтобы дерево оставалось читаемым. Пунктирная рамка — одна страница, зелёная линия — горизонтальная связь двух ключей внутри страницы, серые линии — вертикальные связи между страницами.

Запуск из каталога `saod2`:

```sh
make run-dbd
```

Рисунок открывается через `labs/dbd/preview.html` (если есть графическая среда и `xdg-open`). Его также можно открыть вручную. Сам `dbd.svg` создаётся при запуске программы в каталоге `saod2`.

Используются уже существующие `labs/avl/avl.c` и `labs/avl/common.c`: чтобы не дублировать код, из них берутся `addAVL`, `generateNumbers`, `inorder`, `size`, `checkSum`, `height`, `sumHeight` и `freeTree`. Структура вершины (`Data`, `Bal`, `Left`, `Right`) общая, **но смысл `Bal` в ДБД отличается от АВЛ**.

В таблице высота и средняя высота считаются по **двоичному представлению** (переход по любой ссылке увеличивает глубину на один), как и в лабораторной 3.5. Отдельно `pageLevels` считает логические уровни страниц, где горизонтальная связь внутри страницы не увеличивает уровень.

`B2INSERT` из лекции рассчитан на неповторяющиеся ключи. `generateNumbers` создаёт именно такие ключи.
