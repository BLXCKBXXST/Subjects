# Лабораторная 3.9 — почти оптимальные деревья поиска

А1 — сортировка вершин по убыванию весов и последовательная вставка в дерево поиска.

А2 — на каждом интервале суммируются веса, затем корнем становится первая вершина, на которой накопленный вес достигает хотя бы половины общей суммы. Это **то же правило выбора корня**, что в `coursework/src/a2.c`, с теми же границами рекурсии `L..i-1` и `i+1..R`. В курсовой предварительно группируются одинаковые заглавия, поэтому вместо `A[i].Weight` там `g[i].weight`.

- `a1a2.c` — только алгоритмы А1 и А2.
- `main.c` — запуск и генерация исходного набора.
- `compare.c` — обходы и сравнение характеристик с точным ДОП.
- `manual.md` — ручное построение по 12 символам ФИО.

Для точного ДОП и исходных ключей с весами используются **те же исходные файлы**, что и в лабораторной 3.8: `labs/dop/dop.c`, `common.c`, `tree.c`, `svg.c`.

Запуск из каталога `saod2`:

```sh
make run-a1a2
```

Программа выводит обходы для 100 вершин, сравнение ДОП/А1/А2 для N = 100, 200, 300, 400, 500 и создаёт `a1a2_dop.svg`, `a1a2_a1.svg`, `a1a2_a2.svg` для N = 100. Во всех трёх деревьях используются одни и те же ключи и веса.
