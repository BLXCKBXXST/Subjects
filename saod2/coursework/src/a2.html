Дерево А2 — курсовая

Дерево строится по заглавиям книг. Вес вершины — количество записей с одинаковым заглавием. Масштаб можно менять в браузере.

Дерево показано в исходном масштабе. Для просмотра используйте прокрутку страницы и масштаб браузера.

Дерево ещё не построено. Выполните сортировку и поиск по году в программе.
