## Текущее состояние программы

Реализованы загрузка 4000 записей, постраничный вывод по 20 записей, сортировка индексного массива указателей методом Хоара, двоичный поиск по году, очередь найденных записей, построение из этой очереди приближённого дерева поиска А2, вывод дерева и поиск в нём.

Дерево строится по полю `zagl` — заглавию книги (ФИО героя), которое не совпадает с ключом поиска по году. Вес вершины равен числу записей с одинаковым заглавием в очереди. Для А2 заглавия сортируются, а корень каждого поддерева выбирается при достижении половины суммарного веса. При выборе пункта 3 сначала выполняется поиск по году, затем выводятся очередь и дерево и предлагается поиск по заглавию. Пустой ввод возвращает в меню.

Кодирование (E = 2, метод Шеннона) ещё не реализовано.

Исходный код: [`src/`](src/). Запуск из каталога `saod2/`: `make run-coursework`.
