# Курсовая работа по САОД 2

**Вариант: 12242**

Параметры варианта: `B = 1, C = 2, S = 2, D = 4, E = 2`.

Рабочая база: `testBase1.dat` — книги серии «Жизнь замечательных людей», 4000 записей.

Реализовано:
- загрузка и постраничный вывод базы по 20 записей;
- сортировка индексного массива указателей методом Хоара: по году издания, затем по автору;
- двоичный поиск по году издания с нахождением первого совпадения;
- очередь всех найденных записей.

Исходный код находится в папке [`src/`](src/). Сборка и запуск из `saod2/`: `make run-coursework`.
