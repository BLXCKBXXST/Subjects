# Курсовая работа по САОД 2

## Вариант 12242

По методичке [CURS_WORK20.pdf](../docs/CURS_WORK20.pdf):

| Обозначение | Значение | Что означает для варианта |
|---|---|---|
| **B = 1** | База данных | «Жизнь замечательных людей», файл `testBase1.dat` |
| **C = 2** | Условие сортировки и ключ поиска | Сортировка по году издания, затем по автору; поиск по году |
| **S = 2** | Метод сортировки | Метод Хоара; индексный массив указателей на записи |
| **D = 4** | Тип дерева поиска | Оптимальное дерево поиска, приближённый алгоритм А2 |
| **E = 2** | Метод кодирования | Код Шеннона |

## Текущее состояние программы

Реализованы загрузка 4000 записей, постраничный вывод по 20 записей, сортировка индексного массива указателей методом Хоара, двоичный поиск по году и очередь найденных записей.

Построение дерева поиска (D = 4) и кодирование (E = 2) относятся к дальнейшим этапам курсовой; в текущей версии они ещё не реализованы.

Исходный код: [`src/`](src/). Запуск из каталога `saod2/`: `make run-coursework`.
