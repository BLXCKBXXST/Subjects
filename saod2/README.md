# САОД 2

Лабораторные и остальные материалы по предмету. Номера 3.2 и 3.3 соответствуют пунктам методички из [docs](docs/).

| Задание | Папка | Что внутри |
|---|---|---|
| **3.2 — идеально сбалансированное дерево поиска (ИСДП)** | [labs/isdp](labs/isdp/) | Построение ИСДП, характеристики, таблица, визуализация и два варианта поиска |
| **3.3 — случайное дерево поиска (СДП)** | [labs/sdp](labs/sdp/) | Рекурсивная вставка, вставка с двойной косвенностью, сравнение с ИСДП и визуализация |

Остальные папки: `labs/trees` — предыдущие задания на деревья, `labs/records` — записи, `labs/substring-search` — поиск подстроки, `coursework` — курсовая, `docs` — методички.

## Быстрый запуск

Команды выполняются из **корня репозитория**:

```sh
make -C saod2 build/isdp build/isdp-iterative build/sdp-recursive build/sdp-double

./saod2/build/isdp
./saod2/build/isdp-iterative
./saod2/build/sdp-recursive
./saod2/build/sdp-double
./saod2/build/sdp-recursive +
```

У 3.2 один `main.c`, а рекурсивный и итеративный поиск выбираются при сборке. У 3.3 тоже один короткий `main.c`: варианты отличаются способом вставки, а параметр `+` включает дополнительную таблицу и изображение дерева. Подробности — в README соответствующих папок.
