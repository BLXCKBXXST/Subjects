# Практика 4 — FIFO, вариант 6

Две программы и общий заголовок по заданию. Клиент передаёт имя файла через один FIFO. Сервер обрабатывает файл по варианту из практики 3: находит слово с максимальным количеством букв «а», записывает ответ в новый файл и возвращает его имя клиенту. Клиент выводит содержимое результата.

Имя исходного файла и пример текста те же: input.txt. Алгоритм поиска слова перенесён из практики 3.

В обоих терминалах перейти в папку operating-systems/practice-04.

Первый терминал:

    make
    make run-server

Сервер ждёт клиента. Во втором терминале:

    make run-client

На приглашение клиента ввести input.txt. Результат:

    Слово: абракадабру
    Количество букв 'а': 4

Через FIFO передаётся обычная строка с именем файла и переводом строки. Сервер пропускает строки, которые не являются именами существующих файлов. После чтения запроса он закрывает канал чтения, записывает результат и открывает тот же FIFO на запись. Клиент после отправки запроса закрывает запись и открывает FIFO на чтение.

Файл результата — output.txt. После ответа сервер удаляет FIFO и завершается. Для следующего запроса снова запустить сервер. После принудительной остановки: make clean, затем make.
