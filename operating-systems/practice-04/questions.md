# Контрольные вопросы

1. Могут ли процессы получать непосредственный доступ к данным других процессов? Почему?

Обычно нет: у каждого процесса своё адресное пространство. Для обмена нужны средства ОС, например каналы или специально созданная разделяемая память.

2. Программные каналы. Зачем нужны? Принцип функционирования.

Они передают данные между процессами через буфер в ядре. Одна сторона записывает байты, другая читает их в том же порядке. Обычно такой канал передают от родителя потомку через наследуемые файловые дескрипторы.

3. Функция pipe.

`pipe(fd)` создаёт канал. `fd[0]` нужен для чтения, `fd[1]` — для записи. При успехе функция возвращает 0, при ошибке — минус 1.

4. Именованные каналы и их отличие от программных.

У FIFO есть имя в файловой системе. Поэтому два независимо запущенных процесса могут открыть один канал по известному пути. Обычный канал `pipe` такого имени не имеет.

5. Функция mknod.

Создаёт специальный файл. Для FIFO указывают тип `S_IFIFO` и права доступа, а последний аргумент равен 0. В нашей программе применена специализированная функция `mkfifo`, создающая именно FIFO.
