# Пояснение кода

common.h задаёт имя FIFO, размер буфера и имя файла результата для обеих программ.

Сервер создаёт один FIFO через mkfifo и открывает его для чтения. Клиент спрашивает имя исходного файла и передаёт его строкой с переводом строки.

Сервер читает строки и пропускает те, для которых access(file_name, F_OK) не находит существующий файл. Это распознавание строки с именем файла: по ТЗ информация перед ней игнорируется.

Затем сервер закрывает чтение FIFO и читает исходный файл. Алгоритм из практики 3 перебирает текст. start — начало текущего слова, count — число букв «а» в нём. На границе слова сравниваются count и max. Если найден больший результат, запоминаются число букв и границы слова best, best_end. Русская «а» в UTF-8 сравнивается по двум байтам.

Сервер сохраняет найденное слово и количество букв в output.txt. Потом открывает тот же FIFO для записи и отправляет имя результата.

Клиент после отправки запроса открывает FIFO для чтения, получает имя результата и выводит содержимое этого файла через fgetc и putchar. В конце сервер удаляет FIFO через unlink.
