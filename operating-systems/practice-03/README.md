# Практическая работа №3 — вариант 6

В заданном тексте найти слово с максимальным количеством букв «а» и вывести их количество.

Программа на Си использует pipe() и fork(). Родитель читает input.txt и передаёт текст дочернему процессу через канал, завершая передачу кодом 26. Дочерний процесс находит слово, записывает результат в output.txt и передаёт имя файла родителю через второй канал.

Запуск из папки practice-03 в Linux:

```bash
make run
cat output.txt
```

Для удаления программы и результата: `make clean`.

Пример для input.txt: слово «абракадабру», буква «а» встречается 4 раза. Если таких слов несколько, выбирается первое.
