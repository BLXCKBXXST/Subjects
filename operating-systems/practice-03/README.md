# Практическая работа №3 — вариант 6

Найти слово, в котором больше всего букв «а», и вывести их количество.

Предполагается, что во входном тексте только строчные русские буквы и пробелы. Текст должен помещаться в буфер 5000 байт.

Родительский процесс передаёт текст дочернему через pipe(), завершая передачу кодом 26. Дочерний процесс сохраняет результат в output.txt и возвращает имя файла родителю через второй канал.

Сборка в Linux:

```bash
make
```

Ввод с клавиатуры (по умолчанию, завершение по Enter):

```bash
./practice
```

Чтение текста из файла через перенаправление стандартного ввода:

```bash
./practice < input.txt
```

Чтобы посмотреть результат:

```bash
cat output.txt
```

Команда `make run` собирает и запускает программу с вводом с клавиатуры.
