# Практическая работа №3 — вариант 6

Найти слово, в котором больше всего букв «а», и вывести их количество.

Предполагается, что в тексте только строчные русские буквы и пробелы, а текст помещается в буфер 5000 байт.

Программа создаёт **один канал** с помощью `pipe()` и дочерний процесс с помощью `fork()`.
Родитель передаёт текст в канал и завершает передачу кодом 26. Дочерний процесс читает текст, находит нужное слово и записывает результат в `output.txt`. Затем через **тот же канал** передаёт родителю имя файла. Родитель сначала дожидается завершения дочернего процесса, чтобы не прочитать собственный текст из канала.

Сборка:

```bash
make
```

Ввод с клавиатуры (нажмите Enter после текста):

```bash
./practice
```

Ввод из файла:

```bash
./practice < input.txt
```

Просмотр результата:

```bash
cat output.txt
```

`make run` собирает программу и запускает её с вводом с клавиатуры.
