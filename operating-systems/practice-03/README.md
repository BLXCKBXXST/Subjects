# Практическая работа №3 — вариант 6

Найти слово, в котором максимальное количество букв «а», и вывести это количество (учитывается только строчная «а»).

Предполагается, что во входном тексте только строчные русские буквы и пробелы (строки могут разделяться переводом строки). Текст должен помещаться в буфер 5000 байт.

Родительский процесс читает текст из стандартного ввода и отправляет его дочернему через pipe(), завершая передачу кодом 26. Дочерний процесс сохраняет результат в output.txt и возвращает имя файла родителю через второй канал.

Сборка и запуск в Linux:

```bash
make
./practice < input.txt
cat output.txt
```

Команда `make run` собирает и запускает программу с `input.txt` автоматически.
Для запуска с другим файлом используйте `./practice < другой_файл.txt`.
