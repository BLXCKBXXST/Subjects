# Практическая работа №3 — вариант 6

Найти слово с максимальным количеством букв «а» и вывести количество этих букв.

Ввод: только строчные русские буквы и пробелы; текст не длиннее 4999 байт в UTF-8.
Для обмена родителя и потомка используется **один** канал `pipe()` и `fork()`.
Родитель отправляет текст и код 26; дочерний процесс считает буквы, записывает ответ в `output.txt` и отправляет имя файла родителю через тот же канал. Родитель перед чтением имени ждёт завершения потомка.

Код обходит текст обычным циклом. Для сравнения буквы «а» используются два байта, так как в UTF-8 она занимает два байта.

Сборка: `make`.

Запуск с клавиатуры (ввод заканчивается нажатием Enter):

```bash
./practice
```

Запуск с файлом:

```bash
./practice < input.txt
```

Просмотр результата: `cat output.txt`.
Команда `make run` запускает программу с вводом с клавиатуры.
