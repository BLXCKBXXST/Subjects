# Защита четвёртой лабы, №108

Класс `Hotel` хранит название гостиницы, общее число мест, число заселённых мест и оплату за день. Есть конструктор с параметрами и метод расчёта убытков от пустых мест за месяц.

Из папки `oop`:

```bash
make defense4
make run-defense4
```

Вторая команда сама собирает программу и запускает её из папки с `gost.txt`. Все данные читаются из файла, вводить их руками не нужно.

В [gost.txt](gost.txt) ровно четыре гостиницы. Для каждой на отдельной строке записано название, затем три числа: всего мест, заселено мест, цена за день. Название может содержать пробелы. В файле нет отдельной строки с количеством объектов: их четыре по условию.

`hotel1` и `hotel2` созданы с `static`. `hotel3` и `hotel4` созданы через `new`, в конце освобождаются через `delete`. В `vector<Hotel>` попадают копии гостиниц, в которых занято строго больше половины мест. Ровно 50% не подходит.

Для расчёта принят месяц из 30 дней и неизменное число заселённых мест. Убытки по условию — недополученная оплата:

```text
(всего мест - заселено мест) * цена за день * 30
```

На примере в вектор попадают Северная (80 из 100 мест) и Солнечная (35 из 50). Центральная с 40 из 80 не проходит. Убытки четырёх гостиниц: 1200000, 1800000, 1200000 и 1125000.
