# Как работает защита

Класс `Hotel` описывает одну гостиницу. В `private` находятся четыре поля: название, всего мест, заселено мест и цена за день. Конструктор получает эти значения и записывает их в поля. Для простоты аргументы называются короче: `n`, `total`, `occupied`, `price`.

Метод `monthlyLoss()` сначала вычитает занятые места из общего количества. Получается количество пустых мест. Затем умножает его на цену за день и на 30 дней. Например, из 100 мест занято 80, цена 2000. За месяц получается `(100 - 80) * 2000 * 30 = 1200000` недополученной оплаты.

Метод `isMoreThanHalfFull()` проверяет, что занятых мест больше половины общего количества. `2.0` позволяет получить половину с дробной частью: для 5 мест половина равна 2.5, поэтому 3 занятых места подходят. Занятость ровно 50% не проходит.

Метод `show()` выводит все поля и результат `monthlyLoss()`. `fixed` и `setprecision(2)` задают два знака после точки для денежных величин. `const` после заголовка метода означает, что метод не меняет поля гостиницы.

Функция `readHotel()` читает одну гостиницу из файла. `ifstream& file` — ссылка на уже открытый поток: все вызовы продолжают чтение с текущего места. `getline` получает целое название с пробелами. `ws` пропускает перевод строки перед ним. Через `>>` читаются три числа. Затем вызывается конструктор `Hotel`, и функция возвращает готовый объект.

В `main` открывается `gost.txt`. Из него по очереди читаются четыре гостиницы. Первые две объявлены с `static`, поэтому существуют до завершения программы. Следующие две создаются через `new` в динамической памяти. Переменные `hotel3` и `hotel4` хранят адреса этих объектов. Строка `new Hotel(readHotel(file))` создаёт динамический объект по данным гостиницы, возвращённой функцией чтения. Если файл не удалось открыть, программа сообщает об этом. Остальные данные читаются без проверок: для учебного примера предполагается, что файл заполнен правильно.

Для обычного объекта метод вызывается через точку: `hotel1.show()`. Для указателя — через стрелку: `hotel3->show()`.

Массив `Hotel* hotels[4]` хранит адреса всех четырёх гостиниц, чтобы их можно было перебрать одним циклом. `&hotel1` берёт адрес первого объекта. `hotel3` уже содержит адрес, поэтому перед ним `&` не ставится.

Пустой `vector<Hotel> selected` нужен для отбора. В цикле вызывается `hotels[i]->isMoreThanHalfFull()`. Если условие выполнено, `selected.push_back(*hotels[i])` добавляет копию гостиницы в конец вектора. Звёздочка получает сам объект по его адресу.

`selected.empty()` проверяет, что подходящих гостиниц нет. Иначе следующий цикл выводит все элементы. `selected.size()` возвращает их количество. В конце `delete hotel3` и `delete hotel4` удаляют динамические объекты. Для статических объектов вручную вызывать `delete` нельзя. Вектор сам освобождает свою память.
