# Лабораторная 4

В методичке одно общее задание. Используем класс Airport из первой работы, вариант 24.
Копируем аэропорты с двумя и более полосами в новый вектор, сортируем по числу полос и вставляем новый аэропорт на подходящее место.

[Отчёт](Лаб№4_Язиков.pdf) · [Код](main.cpp) · [Методичка](../materials/lab-04.pdf)

Из папки `lab-04`:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic main.cpp -o lab4
./lab4
./lab4 < example.txt
```

Ввод: число аэропортов; для каждого — название, город, статус и число полос. Затем данные нового аэропорта. Он тоже должен иметь не меньше двух полос. Если выборка пуста, программа сразу сообщает об этом.

Использованы `push_back`, `begin`, `end`, `empty`, `insert`, `size`, `copy_if`, `back_inserter`, `sort`, `lower_bound`, `for_each`.
[result.txt](result.txt): после вставки числа полос идут в порядке 2, 3, 4.
