# Сборка отчётов

Готовые PDF находятся в папках лабораторных. Скрипт оставлен для исправления титульных данных или текста без ручного редактирования PDF.

Нужны Python, пакеты `reportlab` и `Pillow`, а также шрифты DejaVu в `/usr/share/fonts/truetype/dejavu`.

```bash
python reports/build_reports.py
python reports/build_reports.py 3
```

Первая команда обновляет все отчёты, вторая — только третью лабораторную.

ФИО, группа, преподаватель и год указаны в `settings.json`. Для результатов используются сохранённые `result.txt`, код берётся из исходных файлов. Если менялся код, сначала обнови результаты запусков.

Формат: A4, поля 30/15/20/20 мм, основной текст 14 пт, интервал 1.5. Листинги даны уменьшенным моноширинным шрифтом, чтобы строки кода помещались. Титульный лист и разделы повторяют предоставленный образец.
