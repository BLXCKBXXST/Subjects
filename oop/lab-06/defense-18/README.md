# Защита лабораторной 6, вариант 18

Основная программа дополнена вопросом «Хотите добавить нового абонента? (да/нет)» после поиска.

При ответе «да» вводятся данные нового абонента. `lower_bound` находит место по убыванию года рождения, `insert` вставляет абонента. Порядок прежних записей сохраняется. Затем выводится обновлённая очередь. Ответ «нет» завершает программу.

Из папки `oop`:

```bash
make defense6
make run-defense6
```

Готовый пример:

```bash
./build/defense6 < lab-06/defense-18/example.txt
```

В примере добавляется абонент 2004 года рождения. Итоговые годы: 2005, 2004, 2004, 2003, 2002.
