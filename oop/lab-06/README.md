# Лабораторная 6

Вариант 18 — последний в методичке. Класс абонента: ФИО, телефон и день рождения в массиве из трёх чисел.

Программа заполняет очередь, сортирует по убыванию года рождения, выводит её и ищет людей, родившихся в указанное число. Контейнер — deque: он подходит для очереди и допускает сортировку через sort. Поиск сравнивает день месяца, например 12, независимо от месяца и года.

В конце программа спрашивает, добавить ли нового абонента. Ответ «да» — вводим его данные. lower_bound находит место в отсортированной очереди, insert вставляет объект. Остальные абоненты сохраняют свой порядок. После вставки очередь выводится снова. Ответ «нет» завершает программу.

Из папки oop:

```bash
make lab6
make run6
```

Готовый ввод из файла:

```bash
./build/lab6 < lab-06/example.txt
```

Ввод: количество абонентов; для каждого — ФИО и телефон отдельными строками, затем день, месяц и год через пробел. Дальше — день для поиска, ответ «да» или «нет» и при ответе «да» данные нового абонента. Проверок ввода нет.

В примере годы после сортировки: 2005, 2004, 2003, 2002. По числу 12 выводятся Иванов и Петров. Затем добавляется Кузнецов 2004 года рождения; годы становятся 2005, 2004, 2004, 2003, 2002.
