# Лабораторная 3

Вариант 24: ведомость закупок чая из бинарного файла и определение самой продаваемой упаковки.
Сравниваем сумму количеств по каждой упаковке. При равенстве максимума выводятся все лидеры.

[Отчёт](Лаб№3_Язиков.pdf) · [Методичка](../materials/lab-03.pdf)

Из папки `lab-03/variant-24`:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic create.cpp -o create
g++ -std=c++11 -Wall -Wextra -pedantic process.cpp -o process
./create
./process
```

Первая программа читает [tea.txt](variant-24/tea.txt) и создаёт `tea.bin`. Вторая читает бинарный файл, складывает количества по упаковкам, повторно читает файл и печатает ведомость и результат.

Формат `tea.txt`: количество записей; для каждой записи — тип чая, упаковка и производитель на отдельных строках, затем цена и количество через пробел. Дробная часть цены отделяется точкой. Названия занимают не больше 39 байт UTF-8 каждое.

Класс Tea хранит текст в массивах `char`, поэтому в бинарный файл не попадают указатели от `string`. Такой файл рассчитан на ту же платформу и компилятор: после переноса лучше снова запустить `create`. Готовый файл с семью записями тоже добавлен в папку.

[result.txt](result.txt): пачка — 139 шт., пакетики — 111, жесть — 23, фарфор — 76. Сумма ведомости 3665.10 грн. При отсутствии, обрыве или неверных данных файла программа сообщает об ошибке.
