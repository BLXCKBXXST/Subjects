# ООП

Пять лабораторных на C++11. Код, пример ввода и PDF-отчёт лежат в папке каждой работы.

| Работа | Что сделано | Вариант | Отчёт |
|---|---|---|---|
| [1](lab-01) | Класс «Аэропорт» | 24 | [Лаб№1_Язиков.pdf](lab-01/Лаб№1_Язиков.pdf) |
| [2](lab-02) | Треугольник и тетраэдр, наследование | 24 | [Лаб№2_Язиков.pdf](lab-02/Лаб№2_Язиков.pdf) |
| [3](lab-03) | Чтение и обработка бинарного файла | 24 | [Лаб№3_Язиков.pdf](lab-03/Лаб№3_Язиков.pdf) |
| [4](lab-04) | Вектор аэропортов | Общее задание | [Лаб№4_Язиков.pdf](lab-04/Лаб№4_Язиков.pdf) |
| [5](lab-05) | Список людей, поиск по знаку зодиака | 23, последний в методичке | [Лаб№5_Язиков.pdf](lab-05/Лаб№5_Язиков.pdf) |

Из этой папки:

```bash
make          # собрать всё
make run1     # запустить первую работу
make run2     # вторую; аналогично run3, run4, run5
```

Для 2, 4 и 5 есть `example.txt`. Например: `./build/lab2 < lab-02/example.txt`.
Отдельные команды без make написаны в README каждой работы. Файлы сохранены в UTF-8; в Windows нужна консоль с поддержкой UTF-8.

В [materials](materials) лежат все пять методичек. Отчёты: Язиков Денис Александрович, ИКС-531, Моренкова Ольга Ильинична.
