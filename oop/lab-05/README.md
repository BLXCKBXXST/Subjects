# Лабораторная 5

Вариант 23 — максимальный в методичке. Список людей: фамилия, имя, знак зодиака и дата рождения в массиве из трёх чисел.
Из исходного списка создаётся новый список с людьми, у которых указан выбранный знак.

[Отчёт](Лаб№5_Язиков.pdf) · [Код](variant-23/main.cpp) · [Методичка](../materials/lab-05.pdf)

Из папки `lab-05`:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic variant-23/main.cpp -o lab5
./lab5
./lab5 < example.txt
```

Сначала вводится число людей. Для каждого — фамилия, имя, знак зодиака, день, месяц и год. Последняя строка — знак для поиска.
Знаки сравниваются как строки: `Овен` и `овен` считаются разными значениями. Знак вводится пользователем, вычислять его по дате задание не требует.

Работа со списком: `push_back`, `begin`, `end`, `empty`, `size` и итераторы.
[result.txt](result.txt) — пример с двумя найденными людьми. Проверяются даты, включая 29 февраля.
