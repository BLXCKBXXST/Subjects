# Как работает код

Всё устроено как в пятой лабораторной: класс для одной записи, исходный список и новый список после отбора. Вместо человека используется поезд.

Класс `Train` хранит пять полей. `number` — номер поезда, `station` — станция следования, `ticketPrice` — стоимость одного билета, `seats` — число мест, `soldTickets` — число проданных билетов.

Метод `input(ifstream& file)` читает один поезд из уже открытого файла. Номер и числа читаются через `>>`, название станции — через `getline`, чтобы сохранить пробелы. `ws` пропускает перевод строки перед названием.

Метод `unsoldTickets()` вычитает проданные билеты из общего числа мест. Например, при 100 местах и 40 проданных билетах остаётся 60 непроданных. Метод `show()` выводит поля поезда и это количество. `fixed` и `setprecision(2)` оставляют два знака после точки для стоимости.

В `main` открывается `Edem.txt`, затем считывается количество поездов `n`. Создаётся пустой `list<Train> trains`. В цикле создаётся объект `train`, читаются его данные и через `push_back` он добавляется в список.

Следующий цикл выводит исходный список. Итератор `it` начинает с `trains.begin()`, перемещается через `it++` и останавливается на `trains.end()`. Команда `it->show()` выводит текущий поезд.

Затем создаётся пустой список `selected`. Для каждого поезда проверяется `it->unsoldTickets() > it->seats / 2.0`. Если непроданных билетов больше половины мест, `selected.push_back(*it)` добавляет копию поезда в новый список. `*it` — сам текущий объект.

Деление на `2.0` сохраняет дробную часть: половина от 5 равна 2.5, поэтому 3 непроданных билета подходят. Условие строгое, ровно половина не подходит.

Если `selected.empty()` возвращает `true`, программа сообщает, что подходящих поездов нет. Иначе выводятся их количество через `size()` и все найденные поезда. Исходный список сохраняется.
