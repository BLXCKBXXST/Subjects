# Защита пятой лабы, задание 6

Предметная область — вокзал. Класс `Train` хранит номер поезда, станцию следования, стоимость билета, число мест и число проданных билетов. Метод `unsoldTickets()` возвращает число непроданных билетов: всего мест минус продано.

Из объектов создаётся список поездов, у которых непроданных билетов строго больше половины мест. Данные читаются из `Edem.txt`, как дописано в задании.

Из папки `oop`:

```bash
make defense5
make run-defense5
```

Вторая команда сама собирает и запускает программу из папки с `Edem.txt`. Руками ничего вводить не нужно.

Первая строка [Edem.txt](Edem.txt) — количество поездов. Дальше для каждого:

```text
номер поезда
станция следования
стоимость билета  число мест  продано билетов
```

Стоимость одна для всех мест поезда. Название станции может содержать пробелы. Программа ожидает правильно заполненные данные, проверяется только открытие файла.

В примере проходят поезда 101 и 404: у них свободны 60 из 100 и 3 из 5 мест. Поезд 202 с 40 непроданными билетами из 80 не проходит: это ровно половина.
