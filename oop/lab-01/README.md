# Лабораторная 1

Вариант 24: аэропорт, статус и количество полос. Название и город добавлены как дополнительные поля.

[Отчёт](Лаб№1_Язиков.pdf) · [Методичка](../materials/lab-01.pdf)

Основная программа: [airport_basic.cpp](variant-24/airport_basic.cpp). Сам класс находится в [airport.h](variant-24/airport.h), чтобы использовать его ещё и в четвёртой работе.
Программа создаёт объект, показывает его, меняет все четыре поля и вызывает все методы чтения полей. Данные учебные.

Из папки `lab-01`:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic variant-24/airport_basic.cpp -o lab1
./lab1
```

[result.txt](result.txt) содержит вывод запуска. В [airport_extended.cpp](variant-24/airport_extended.cpp) сохранена прежняя дополнительная версия с датой открытия. Она собирается отдельно, в текущий отчёт не входит; проверки даты в ней нет, а формула века ошибается на годах, кратных ста.
