# Лабораторная 2

Вариант 24: равносторонний треугольник и его наследник — правильный тетраэдр.
Программа считает среднюю площадь N треугольников и находит тетраэдр с наименьшим объёмом из M объектов.

[Отчёт](Лаб№2_Язиков.pdf) · [Код](variant-24/main.cpp) · [Методичка](../materials/lab-02.pdf)

Из папки `lab-02`:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic variant-24/main.cpp -o lab2
./lab2
./lab2 < example.txt
```

Сначала вводятся N и M, затем N сторон треугольников и M рёбер тетраэдров.
Нулевое количество допускается. Стороны должны быть положительными. При одинаковых минимальных объёмах выводится первый найденный тетраэдр.

`virtual` и `override` нужны для полиморфизма: вызов `show()` через указатель на треугольник выводит сведения о тетраэдре.
[result.txt](result.txt) — результат для примера: средняя площадь 8.083, минимальный объём 0.943 у второго тетраэдра.
