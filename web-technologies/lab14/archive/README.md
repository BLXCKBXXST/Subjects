# Архив лабораторной №14 — Интерактивное резюме

[Архивная PDF-копия](lab14_archival.pdf) собрана из сохранившегося исходного LaTeX. **8 оригинальных иллюстраций не сохранились**: в архивной копии они опущены. Исходные LaTeX-файлы в [latex-report/](../latex-report/) оставлены без изменений; в README добавлена ссылка на архив. Это не оригинальный PDF, сдававшийся преподавателю.

Два снимка заново созданы при открытии сохранённого сайта в браузере. Они не показывают прежний продакшн-сервер, его TLS или Docker. Исторические изображения редактирования, ripple и диалога печати отсутствуют.
