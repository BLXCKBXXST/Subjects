# Отчёт: лабораторная №14 — Интерактивное резюме

Исходники отчёта находятся здесь. **Готового PDF и скриншотов в репозитории нет:** сначала нужно подтвердить выполнение работы своими изображениями. Список из 8 файлов — [screenshots/README.md](screenshots/README.md). Все кадры положи в `img/` (если папки нет — создай), с указанными там именами.

Снимки 01–06 — локальная работа резюме, редактирование, эффект Material Wave, печать в PDF и мобильная версия. 07–08 относятся к развёртыванию на сервере. Если разворачивал на другом домене или без Docker, скорректируй `parts/chap2.tex` и `parts/chap3.tex` вместе с подписями.

## Сборка

Сначала проверь ФИО, группу, преподавателя и год в `config.tex`, а в главах — адреса и ссылки, относящиеся к твоему выполнению. Из корня клона `Subjects` собери отдельный ZIP:

```bash
cd web-technologies/lab14/latex-report
mkdir -p img
zip -r ../lab14_overleaf.zip main.tex config.tex parts fonts img
```

В Overleaf: **New Project → Upload Project** → загрузи архив → **Menu → Compiler: XeLaTeX**, главный файл `main.tex`. ZIP содержит исходники, не готовый PDF. Если работаешь в Windows, упакуй те же пять объектов через Проводник — без внешней папки `latex-report` внутри архива.

Пока какого-то изображения нет, при компиляции на его месте появится рамка **«СКРИНШОТ НЕ ДОБАВЛЕН»**. Это удобно при подготовке, но перед сдачей замени все рамки реальными снимками и пролистай итоговый PDF. Общие рекомендации — [REPORTS.md](../../REPORTS.md).
