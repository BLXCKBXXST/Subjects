# Архив веб-технологий

Дисциплина завершена. Этот раздел — **сохранённый учебный архив**, а не перечень работ, которые нужно доделывать. Исходные программы, методички и оригинальные LaTeX-отчёты оставлены на местах.

## Что сохранилось

- **Лабораторные 4–9:** оригинальные PDF, изображения выполнения, скрипты настройки Ubuntu/VirtualBox. Например, [папка отчёта №4](lab4/latex-report/).
- **Лабораторные 10–14:** сохранились тексты LaTeX и исходники, но не исторические скриншоты и не итоговые PDF. Из исходников собраны пять **архивных PDF-копий** с приложениями из 20 заново полученных иллюстраций. Пропавшие оригинальные рисунки в этих PDF опущены, а не заменены выдуманными скриншотами Figma, Codepen или старого сервера.
- **Лабораторная 15:** [решения Python/Stepik](lab15/README.md); отдельного LaTeX-отчёта в архиве не было.
- **РГЗ:** [проект видеохостинга](RGZ/) и [сохранённый PDF](RGZ/latex-report/RGZ_latex_report.pdf).

**Как читать PDF:** это архивная публикация сохранившегося текста отчёта с новыми иллюстрациями из сохранённого кода. Она не является восстановленным оригиналом сданного PDF и не подтверждает недоступные теперь этапы выполнения. В начале каждого PDF есть примечание о сохранности; в приложении объяснено происхождение новых изображений.

## Что где находится

В каждой лабораторной сохранён первоначальный каталог [latex-report/](lab10/latex-report/) с исходниками и исторической инструкцией. Отдельная папка archive/ содержит новую PDF-копию, описание сохранности и рендеры в evidence/. Оригинальные исходники не переписывались ради архивной версии.

Прежние требования сделать 54 оригинальных скриншота для лабораторных 10–14 **не относятся к поддержанию этого архива**. Они оставлены в [REPORTS.md](REPORTS.md) и списках screenshots/README.md только как историческая инструкция.

## Воспроизводимость

Скрипт [tools/archive_web.py](tools/archive_web.py) повторно отображает сохранённые HTML/JS, создаёт отдельную копию LaTeX без отсутствующих рисунков и добавляет приложение. Потребуются Python, Playwright с Chromium, Pillow, Node.js и XeLaTeX. Исходные отчёты он не изменяет. Для начального построения архива использовался одноразовый GitHub Actions; постоянная автоматическая сборка ZIP не возвращалась.
