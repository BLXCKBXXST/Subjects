# Отчёт по РГЗ — видеохостинг

В этой папке уже сохранён [PDF отчёта](RGZ_latex_report.pdf), исходный `main.tex`, `config.tex`, главы в `parts/` и изображения в `img/`. Перед повторной сдачей проверь, что описанные в отчёте функции, изображения и адрес сервера соответствуют **текущей** версии проекта. Общая инструкция по [сборке отчётов](../../REPORTS.md) подходит и сюда.

Если нужен новый PDF, измени исходники и собери их с **XeLaTeX** из этой папки. Для Overleaf создай ZIP из `main.tex`, `config.tex`, `parts/`, `fonts/` и `img/`; `main.tex` должен находиться в корне архива. Пожалуйста, не считай сохранённый PDF автоматически актуальным после правок в приложении.
